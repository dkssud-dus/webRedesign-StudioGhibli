# Studio Ghibli
![mainpage-visual](https://github.com/user-attachments/assets/e65663c1-8d26-42c2-b258-58ae3552d7e9)

<br/><br/>

**Official Studio Ghibli website redesign project with multilingual support and intuitive UI for global fans**
> This project is a 3-person collaborative effort aimed at creating a multilingual web portal that preserves Studio Ghibli's brand identity while providing easy access for fans worldwide. It includes a main page and nine sub-pages, incorporating accordion, search, and filter features for handling large amounts of information, as well as media elements such as music and video playback. The result focuses on user experience that simultaneously satisfies accessibility, readability, and branding.

## Overview
### Background
Studio Ghibli is a globally recognized animation brand with numerous fans not only in Japan but also overseas. However, the official website only supports Japanese, significantly limiting accessibility for international fans. Additionally, user-friendly and necessary features (search, top button, etc.) were lacking, potentially causing difficulties in usage. Both the main page and sub-pages displayed information in simple text format, failing to properly utilize Studio Ghibli's intellectual property.

<br/>

### Purpose
- We want to materialize the brand image of 'Studio Ghibli'.
- We want to serve as a portal that delivers not only official information but also cultural content.
- We want to create a global site that is easily accessible to fans worldwide, not just domestic Japanese fans.

<br/>

### Keywords
`Warmth, Coziness`
- Studio Ghibli's unique sensibility
- Fairy tale-like atmosphere
- Maximizing visual appeal
  
`Multilingual Support`
- Official hub for Studio Ghibli fans worldwide

`Intuitiveness`
- Simple and clear, considering user convenience

### Music On/Off
**Summary**
- When accessing the main page, a screen for music activation appears first.
- Users can choose to activate music with `ON` / `OFF`, and afterward, they can activate music using the `mute button` and `play button` at the bottom right of the screen.

- Clicking the `hamburger button` brings up a full-screen `navigation`, with each menu arranged in a single line for easy finding.
- When hovering over the menu, images are inserted to create a colored effect.
