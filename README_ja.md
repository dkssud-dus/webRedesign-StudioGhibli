# Studio Ghibli
![mainpage-visual](https://github.com/user-attachments/assets/e65663c1-8d26-42c2-b258-58ae3552d7e9)

<br/><br/>

**グローバルファンのための多言語対応と直感的UIで再構成したStudio Ghibli公式ウェブリデザインプロジェクト**
> 本プロジェクトは、Studio Ghibliのブランドアイデンティティを活かしながら、世界中のファンが簡単にアクセスできる多言語ベースのウェブポータルを作ることを目的とした3人の協業プロジェクトです。メインページと9つのサブページを含み、大容量情報伝達のためのアコーディオン、検索、フィルター機能と音楽・動画再生などのメディア要素を統合しました。結果的に、アクセシビリティ・可読性・ブランディングを同時に満足させるユーザーエクスペリエンスを指向しました。

## Overview
### Background
スタジオジブリは世界的なアニメーションブランドとして、日本国内のファンだけでなく海外にも多くのファンを抱えています。しかし公式ホームページの場合、日本語のみサポートしており、海外ファンのアクセシビリティが著しく低い状況でした。また、ユーザーを考慮した利便性・必要性機能（検索、トップボタンなど）が乏しく、利用に困難を感じる可能性がありました。メインページとサブページの両方で情報を単純な文章列で配置し、スタジオジブリのIPを適切に活用できていない姿を見せていました。

<br/>

### Purpose
- 「スタジオジブリ」というブランドのイメージを具体化したい。
- 公式情報だけでなく、文化コンテンツまで伝達するポータルの役割を果たしたい。
- 日本国内のファンだけでなく、世界中のファンが簡単にアクセスできるグローバルサイトを作りたい。

<br/>

### Keywords
`温かさ、居心地の良さ`
- スタジオジブリ独特の感性
- おとぎ話のような雰囲気
- 視覚的魅力の最大化
  
`多言語対応`
- スタジオジブリの世界中のファンのための公式ハブ

`直感性`
- 簡潔で明確に、ユーザーの利便性を考慮

### Music On/Off
**Summary**
- メインページにアクセスする際、音楽の有効化可否画面が最初に登場します。
- `ON` / `OFF`で有効化可否を選択し、その後も画面下段右側に`ミュートボタン`と`再生ボタン`で音楽を有効化できるようにしました。
- 背景画面と`GIF`画像はスタジオジブリのIPを活用し、初めてユーザーがページにアクセスした時に「スタジオジブリ」のイメージを強く印象づけられるようにしました。

### Header + Navigation
**Summary**

- 右側には`検索ボックス`・`グローバルボタン`・`ハンバーガーボタン`を配置しました。
- `グローバルボタン`をクリックした場合、韓国語・英語・日本語で`言語を変更`できるようにしました。
- `ハンバーガーボタン`をクリックした場合、画面を埋め尽くす`ナビゲーション`が登場し、各メニューは見つけやすいように一行で配置されました。
- 該当メニューをホバーした場合、画像を挿入して塗り絵のような効果を表現するようにしました。

### スタジオジブリ
**Summary**
- `メインビジュアル`と続く領域です。
- `メインビジュアル映像`にオーバーレイが重ねられ、背景映像が暗く見える形で制作されました。
- 左側にはスタジオジブリについての簡単な説明が配置され、`もっと見るボタン`でサブページ「会社紹介」に移動可能です。
- 右側にはスタジオジブリの作品年表がアニメーション効果で↑方向に移動し、`マウスの侵入`により`停止`が可能です。
- 右側の作品タイトルを`クリック`した場合、後ろの背景が画像`スワイパー`に転換され、各作品の画像を見ることができるようにしました。

- また、進行中のイベントも確認可能にするため`スワイパー`を使用し、ボタンを押してイベント内容を確認できるようにしました。
